设置

GitHub 接口

未登录时 GitHub 每小时只允许 60 次接口调用、搜索每分钟 10 次。填入个人访问令牌（ settings/tokens ，只需 public_repo 只读权限）后可提升到每小时 5000 次。

汉化翻译

MyMemory 免费额度约每天 5000 词（按出口 IP 计算），一次长 README 汉化就可能耗尽。免费引擎下自动汉化 README 会先翻前 2500 个字符，其余内容可点「重新汉化」继续或切换 AI 翻译（无每日额度限制，可整篇自动汉化）。

兼容 OpenAI 协议的国内服务同样可用，例如 DeepSeek（https://api.deepseek.com/v1）、Moonshot、通义等。

百度通用翻译接口地址已内置（https://fanyi-api.baidu.com/api/trans/vip/translate），无需填写；只需填 APP ID 与密钥。标准版 QPS 为 1，程序会自动限速并按错误码重试。

有道接口地址已内置（https://openapi.youdao.com/api），使用 v3 签名，无需填写；应用 ID 与应用密钥需成对填写，任何一个缺失都会回退到免费在线翻译。获取路径：ai.youdao.com → 控制台 → 应用管理 → 我的应用（新建「文本翻译」应用）。

关于 StarHub

StarHub 是一个 GitHub 高星项目聚合桌面客户端：

  • 按用途分类浏览（13 个用途分类 + 「全部」汇总视图 + 全站高星榜，其中「应用」跨类收纳所有成品应用）
  • 按 Star 数 / Release 下载量 / 首字母 A-Z 排序
  • 每个仓库自动打上中文标签（形态 + 用途），点击标签或在搜索框输入标签即可筛选
  • 应用内渲染 README 预览，无需跳转浏览器
  • 外语自动汉化：自动识别英 / 日 / 韩 / 俄 / 西 / 法 / 德等语种，简介与 README 都可在后台自动译成中文（支持 AI 翻译 / 百度翻译 / MyMemory 免费接口 / 离线术语表）
  • 一键打开原站地址、复制链接
  • 收藏与点赞，数据保存在本机

内置精选库中的中文名与简介为人工整理；在线接口数据版权归 GitHub 及各仓库作者所有。
